## Variant: Playful Social

### Design stance
A trip is a group chat with a plan attached. Wanderaid is where friends coordinate — avatars, activity, and a little delight.

### Key choices
- **Layout:** hero trip card + "What's new" activity feed + upcoming mini-cards + floating New Trip FAB
- **Typography:** bold rounded system sans, friendly sentence casing
- **Color:** warm cream background; per-feature colors mapped from AppTheme.FeatureColor (people purple, places red, expenses blue, chat light blue, map green, itinerary orange)
- **Interaction:** real bottom-sheet New Trip modal with date/attendee inputs and a create confirmation

### Trade-offs
- Strong at: social energy, feeling alive (activity feed), clear feature color-coding
- Weak at: serious/tool contexts, longer-term historical browsing (feed takes space)

### Best for
The Discord-style coordination the product brief calls for — small friend groups who want to *see* each other in the app.
