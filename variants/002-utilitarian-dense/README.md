## Variant: Utilitarian Dense

### Design stance
Wanderaid is a tool for running trips: every pixel earns its place, information density is a feature, and the current trip is the cockpit.

### Key choices
- **Layout:** segmented Current/Upcoming/Past tabs filter one list; summary card pinned on top
- **Typography:** compact system sans, mono numerals for dates and money
- **Color:** cool grays (#F5F6F8), near-black ink, single brand blue (#1A75D1 — matches current AppTheme.primary)
- **Interaction:** real tab filtering with live trip counts, hover rows

### Trade-offs
- Strong at: scanning many trips fast, power users, data clarity (dates/money in mono)
- Weak at: emotional warmth, marketing appeal, photo storytelling

### Best for
Organizers juggling several trips who want maximum glanceable info. Closest to the current app's density but tighter.
