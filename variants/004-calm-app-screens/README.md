## Variant: Calm App Screens

### Design stance
App-wide extension of the selected Calm User Dashboard direction across the major Wanderaid surfaces.

### Screens included
- Current Trip / Trip Detail
- All Trips
- Expenses / Balances
- People / Participants
- Places
- Itinerary / Planning
- Create / Join / Invite
- Confirmation / destructive action pattern

### Key choices
- Layout: One interactive phone mockup with tabs so each surface can be reviewed as part of a single system.
- Typography: Same serif display moments and system-body readability as the selected dashboard.
- Color: Shared warm light/dark tokens, forest-green actions, amber/terracotta semantic accents.
- Interaction: Screen tabs, light/dark toggle, and a working destructive confirmation modal.

### Trade-offs
- Strong at: seeing whether the visual language scales beyond the dashboard before implementing every SwiftUI surface.
- Weak at: final per-screen edge cases; these are direction sketches rather than exhaustive production specs.

### Best for
- Reviewing app-wide consistency before turning the selected direction into reusable SwiftUI components and page-specific implementation tasks.
